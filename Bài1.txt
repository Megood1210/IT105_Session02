I.Hệ thống quản lý thư viện
| Vai trò Stakeholder    |Đối tượng cụ thể                                                           | Mô tả vai trò trong dự án                                                                                    |
|------------------------|---------------------------------------------------------------------------|--------------------------------------------------------------------------------------------------------------|
| 1. Người dùng cuối     | - Thủ thư                                                                 | - Sử dụng hệ thống hằng ngày: mượn, trả, tra cứu sách                                                        |
|                        | - Sinh viên / Độc giả                                                     | - Góp ý về tính năng, giao diện, quy trình sử dụng                                                           |
|----------------------- |---------------------------------------------------------------------------|--------------------------------------------------------------------------------------------------------------|                                                                                                                                                                                                                                                                                                                                              
| 2. Sponsor             | - Ban giám hiệu trường / Ban quản lý thư viện                             | - Cung cấp kinh phí, phê duyệt dự án                                                                         |   
|                        |                                                                           | - Đặt mục tiêu, phạm vi, thời hạn triển khai                                                                 |
|------------------------|-------------------------------------- ------------------------------------|--------------------------------------------------------------------------------------------------------------|                                                                                                                                                                                                                                                                                                                                              
| 3. Chuyên gia nghiệp vụ| - Cán bộ nghiệp vụ thư viện                                               | - Hiểu rõ quy trình nghiệp vụ thư viện (quản lý mượn trả, xử lý trễ hạn, cập nhật tài liệu)                  |
|                        | - Quản lý kho sách                                                        | - Tư vấn quy trình thực tế để nhóm phát triển thiết kế hệ thống sát nhu cầu                                  |
|------------------------|---------------------------------------------------------------------------|--------------------------------------------------------------------------------------------------------------|                                                                                                                                                                                                                                                                                                                                              
| 4. Bộ phận kỹ thuật    | - Quản trị hệ thống                                                       | - Phân tích, thiết kế, phát triển, kiểm thử và triển khai hệ thống                                           |
|                        | - Lập trình viên                                                          | - Quản lý cơ sở dữ liệu, bảo mật và hiệu năng hệ thống                                                       |
|                        | - Kiểm thử viên                                                           |                                                                                                              |
|----------------------- |---------------------------------------------------------------------------|--------------------------------------------------------------------------------------------------------------|                                                                                                                                                                                                                                                                                                                                              
| 5. Bên thứ ba          | - Nhà cung cấp phần mềm thư viện (hệ thống RFID, API thanh toán tiền phạt)| - Cung cấp công nghệ, API hoặc tích hợp các hệ thống bên ngoài (ví dụ: xác thực sinh viên, thanh toán online)|                                                               
|                        | - Dịch vụ hosting hoặc cloud                                              |
